# FFXIV site family

Every HTML page under `/mods/ffxiv/` uses the same shell, generated by native
Imba in `imba/scripts/project-pages.imba`. The hub, project pages, votes,
previews, installation page, gallery, model leaderboard and account utility
pages share a masthead, navigation, project context, footer and theme control.
Project artwork and page-specific controls retain their own identities.

`public/mods/ffxiv/site/site.css` owns the palette, typography, surfaces and
responsive layout. Functional stylesheets load first; the shared stylesheet
loads last. Legacy ballot and gallery surface names resolve to shared tokens.
Every page uses system fonts; no font-service request is made.

`imba/public/mods/ffxiv/site/theme.imba` applies the stored preference before
paint and owns the visible toggle. It preserves the existing storage key and
supports automatic, dark and light modes, including cross-tab updates. Older
standalone scripts defer their toggle handler when the shared owner is present.
The preview canvas retains its own readable simulation colors.

The complete page remains HTML. Context tabs, the cross-project vote chooser
and footer links work without a client router. Imba search and queue controls
continue to enhance the ordinary pages. IDs used by ballots, gallery uploads,
account linking and moderation remain intact; API authorization is unchanged.

The build checks the shared shell for drift and idempotence. Tests require one
header, main, footer and theme toggle, a common final stylesheet, intact page
control IDs and no inline code or remote font stylesheet. Deployment checks
read every generated HTML route. Browser acceptance includes all 39 pages in
desktop and mobile layouts, matching typography/palette and persistent theme
cycles, plus ballot rendering, preview controls, search, filtering, reduced
motion and JavaScript-disabled fallbacks.
