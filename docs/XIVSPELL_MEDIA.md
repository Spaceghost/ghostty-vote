# XivSpell website media

Published route: `https://spacegho.st/mods/ffxiv/xivspell/`.

## Illustration

Final asset: `public/mods/ffxiv/site/art/xivspell-banner.webp` (1737 × 905).
Generated with the built-in `image_gen` tool, then encoded as WebP with ImageMagick.
This is concept illustration, labelled as such on the page; it is not game UI.
The original is retained under the generation tool's normal output directory.

Prompt used:

> Create a polished wide landscape hero illustration for XivSpell, an open-source Final Fantasy XIV spell-weaving mod, for a website family with deep midnight-blue backgrounds, warm gold serif project titles and luminous restrained aqua magical motifs. Composition about 1.92:1. On the right two-thirds: an exquisitely illustrated open leather-bound grimoire floating above worn pale stone in a moonlit coastal fantasy library, a small radiant turquoise crystal behind it, restrained concentric magical timing rings around the book and a few ivory keyboard keycaps and golden rune diamonds flowing into the pages. Beautiful material detail: vellum, engraved brass, midnight leather, soft cyan light, tiny warm dust motes. Painterly editorial fantasy illustration, designed, elegant and legible, not noisy or generic neon. Left third is calm navy negative space with the single exact warm-gold serif title 'XivSpell' and a delicate gold horizontal rule beneath it; no other text. Match a refined unofficial Eorzean illustrated-mod website, not a fake game screenshot. No UI panels, no game HUD, no guitar-hero lanes, no controller, no logos, no watermark. Highest visual quality, rich atmospheric depth, cohesive gold/navy/cyan palette.

The small companion mark, `public/mods/ffxiv/site/art/xivspell-icon.svg`, is a
repo-native vector in the existing gold/navy/aether icon style.

## Recorded game capture

Final asset: `public/mods/ffxiv/xivspell/media/grimoire-in-game.webp` (1920 × 1080).
Captured from the running game with `grim` on 2026-11-07 after XivSpell 0.1.0.5
was loaded. The screenshot shows the real embedded reverse pulse, queued runes,
source-built spell UI and a 120 BPM tempo guide. It is not evidence of a Piano
song chart or controller acceptance. There are no fabricated or composited UI
elements. Image metadata was stripped during WebP encoding.

The close-up is a CSS crop of this same complete capture, linked to the full
image. The page captions distinguish it from the illustration. The full asset
was visually inspected before publication; no chat, account credentials or
terminal contents are visible. Other interface panels belong to the installed
HUD family and are not presented as XivSpell features.

Content and installation state come from the XivSpell source at
`Spaceghost/xivspell-dalamud`, commit `0c245f74cef65b91310e2987010241e43bdc138e`.
Source-only publication is intentional: the project has no claimed one-click
installer release, and the website registry leaves its installer flags disabled.
