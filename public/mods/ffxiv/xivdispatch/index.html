XivDispatch

Slack, within reach.

A practical Slack companion project for FFXIV: DMs, mentions, threads and persistent drafts, with quiet play sessions and optional Prism panels.

Current status

design preview; live plugin and native companion apps are not released. The interactive preview uses invented data. Live game integration, native companion apps and hardware support have not yet been verified.

The conversations you actually need

The first dedicated interface is planned around DMs, mentions and pinned channels. Read a thread, keep a draft, react or open the original message. The interactive preview uses a fictional workspace and never connects to Slack.

A useful path before a complete custom client

First evaluate hosting the official Slack app window through Desktop and Ghostty in the Wine/Linux setup. A dedicated compact interface then uses supported Slack APIs and workspace-authorized access. Official app hosting is planned, not verified.

Your identity, your deliberate send

A real client needs authorized user access, rather than silently substituting a bot identity. Credentials stay in the connector on a trusted device. Sending and reactions are explicit actions; an assistant never sends merely because a message appeared.

Quiet while you play

Choose when a conversation deserves attention. Compact notifications, a quiet session and drafts that survive closing the panel make a more useful first release than an attempt to reproduce every Slack feature.

A conversation panel for Prism and Camp

Dispatch will offer a compact panel for glasses or another display and a larger window in a Camp arrangement. Viewers receive only the conversations you choose. A controller should open or dismiss a panel without stealing ordinary game input.

What still needs proving

OAuth, workspace installation policy, event delivery, history limits, message identity and permission revocation need integration checks. There is no Slack connection, live account access or installable Dalamud plugin in this publication.

Preview and source

The interactive browser preview and its native Imba source are available now. No installable Dalamud plugin or native companion app is released yet.

The browser preview needs no game, account or glasses. Live integrations are planned.
