Bundled, independently optional providers

XivHud.Windowing provides exact-identity Ghostty window adoption. XivHud.Windowing.Dalamud provides native frames using pinned KamiToolKit. XivHud.Protocol supplies the versioned snapshot and bounded operation queue. They ship with consuming modules.

IPC and ownership

The HUD host, Journal and Character expose versioned JSON Call gates. Reads return immutable snapshots; changes are validated, queued, applied on the framework thread and polled by request ID. Controller ownership stays with a focused local window and is never offered as an MCP operation.

See the IPC contract and the module READMEs for lifecycle, window identity and build instructions.

Install and build

This library is bundled with Journal and Character. It has no separate Dalamud installer entry.

Build instructions and verification records are in the project README.
