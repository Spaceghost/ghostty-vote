Your next chapter, on warm vellum.

An illustrated quest journal with accepted quests, local bookmarks, search, and native map handoff. Optional native frames and world windows.

SourceInstall / buildGallery
Current status

experimental · selected Journal and window checks observed in game. Verification below describes earlier recorded checks; the new publication and IPC work have offline validation.

Your next chapter

Search accepted quests by title, chapter or current objective. Keep local bookmarks and choose a parchment or night palette. The book uses your installed game’s quest icons and fonts.

Open, map, return

Use your normal Journal action, the optional Umbra toolbar or /xivjournal open. Show a selected quest on the game map, or return to the complete original Journal with /xivjournal native. Bookmarks do not alter native tracking.

Choose a window

/xivjournal screen opens an ordinary window; /xivjournal frame chooses a native frame; /xivjournal world requests a Ghostty window. Native frames and world hosting are optional. The controller service yields when focus is lost.

What has been checked

Earlier builds showed a live accepted quest, its native map handoff, day/night appearance, native-frame popups, world-window focus and unload/reload cleanup. Physical controller buttons, dragging/scaling and all world placements remain unverified. The replacement currently covers accepted normal quests; full history and other quest modes remain in the original.

Install and build

Add https://spacegho.st/mods/ffxiv/plugins.json in Dalamud’s Experimental settings and enable plugin testing builds. These are experimental builds. The installation page explains the repository and the build-it-yourself path.

Dalamud API 15. Ghostty world windows and the Umbra toolbar are optional.

Build instructions and verification records are in the project README.
