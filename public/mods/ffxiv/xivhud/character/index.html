development · builds and offline tests; in-game acceptance pending. Verification below describes earlier recorded checks; the new publication and IPC work have offline validation.

An adventurer’s record

Four pages show your equipped gear, attributes, classes and jobs, and saved gear sets. Equipment includes materia, condition, glamour and dyes. The record uses the installed game’s artwork and fonts.

Open the familiar way

Use the game’s Character action, the optional Umbra toolbar or /xivcharacter open. /xivcharacter native opens the original and /xivcharacter screen recovers the ordinary window. Native frames and Ghostty hosting are optional.

Development source and package

Character builds against matched API 15 references and has extensive offline tests. It has not yet been loaded into the game in the recorded verification. Its package is for manual development testing and is held out of the shared installer until live acceptance.

Next checks

Validate native adoption and fallback, displayed item level, equipment slot order, job experience, gear-set results, controller navigation and each window host against the original game windows. A 3-D character preview and appearance editing are future work.

Install and build

Build from the HUD family source, or use its explicitly marked development package. Character is held out of the automatic installer pending live acceptance.

Dalamud API 15. Ghostty world windows and the Umbra toolbar are optional.

Build instructions and verification records are in the project README.
