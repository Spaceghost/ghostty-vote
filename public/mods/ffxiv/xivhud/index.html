XivHud

An illustrated interface, with the original always within reach.

A reversible native HUD mode and shared controller support for an illustrated interface. Restore the native HUD with /xivhud off.

SourceInstall / buildGallery
Current status

experimental · HUD restoration observed in game; new IPC awaits live checks. Verification below describes earlier recorded checks; the new publication and IPC work have offline validation.

Three modules, one illustrated interface

XivHud controls native HUD visibility. Journal is your illustrated quest book. Character is your adventurer’s record. Journal and Character are independently loadable; the shared controller host is optional for mouse and keyboard use.

Keep the original within reach

Click the HUD entry in Umbra’s server-info bar or use /xivhud on. Restore chat, nameplates and action bars with /xivhud off. Your saved HUD layout is preserved, and unloading releases the visibility change.

Windows that fit the moment

Journal and Character start as ordinary screen windows. Choose a native game frame or, with Ghostty installed, place the same illustrated window in the world. Return anytime with /xivjournal screen or /xivcharacter screen.

Your assistant can see the interface

The new XivMcp integration reads every module’s readiness, current window mode and selection. Explicit UI changes wait for your approval. It can open a chapter, select a Character page or restore a screen window without simulating controller input.

What has been checked

Earlier development builds demonstrated HUD toggling and restoration, plus focused controller ownership in Journal. Full logout/relogin, combat, cutscene transitions and physical controller navigation still need acceptance. The new IPC is covered by offline tests; it has not been exercised in a running game here.

Install and build

Add https://spacegho.st/mods/ffxiv/plugins.json in Dalamud’s Experimental settings and enable plugin testing builds. These are experimental builds. The installation page explains the repository and the build-it-yourself path.

Dalamud API 15. Ghostty world windows and the Umbra toolbar are optional.

Build instructions and verification records are in the project README.
