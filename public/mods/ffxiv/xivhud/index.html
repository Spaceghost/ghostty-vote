XivHud

An illustrated interface, with the original always within reach.

A shared illustrated Dalamud interface, optional Umbra toolbar family and independent floating-window host. Restore native HUD visibility with /xivhud off.

SourceSource / buildGallery
Current status

experimental · live module, floating-window and recovery checks recorded. HUD restoration was observed in earlier builds. HUD, Journal and Character modules loaded and exposed read-only IPC snapshots in the recorded checks. UI mutations, visual transitions and physical controller navigation still require acceptance.

One illustrated Umbra family

Journal, Character, Vitals, Combat, Correspondence, Inventory, Crafting and Floating Windows form one interface family. Explore every module, toolbar adapter and presentation option.

Keep the original within reach

Click the HUD entry in Umbra’s server-info bar or use /xivhud on. Restore chat, nameplates and action bars with /xivhud off. Your saved HUD layout is preserved, and unloading releases the visibility change.

Windows that fit the moment

Screen and native frames remain available. XivHud.Windows provides independent floating presentation for open plugin windows without a Ghostty session. Journal and Character choose this service by default for world mode; their appearance settings can explicitly select the existing Ghostty host. Recover all standalone windows with /xivwindows screen.

Your assistant can see the interface

The new XivMcp integration reads every module’s readiness, current window mode and selection. Explicit UI changes wait for your approval. It can open a chapter, select a Character page or restore a screen window without simulating controller input.

What has been checked

The nine modules and eight Umbra adapters loaded in game. Recorded checks cover standalone Journal placement and its settings popup, Inventory selection, beside-character projection, screen recovery, and Crafting worklist totals. All 560 offline tests pass. Physical controller navigation and scene depth occlusion remain unverified.

Install and build

Add https://spacegho.st/mods/ffxiv/plugins.json in Dalamud’s Experimental settings and enable plugin testing builds. These are experimental builds. The installation page explains the repository and the build-it-yourself path.

Dalamud API 15. Umbra and Ghostty are optional; ordinary plugin windows can float through XivHud.Windows.

Build instructions and verification records are in the project README.
