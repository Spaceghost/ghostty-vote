FFXIV mods/Feature queue

Voted feature queue

235 accepted features. Snapshot: 2026-10-13 UTC.

How features enter the queue and what comes first

Preserve the 201 features accepted in the confirmed ballot. For newer projects, queue ideas with more Want votes than Maybe and Skip combined. Previously excluded ideas require a new acceptance decision.

Order: feasibility, estimated effort, Want votes, then the catalogue’s top-pick and value signals. Estimates describe the idea, not a delivery date. Shared dependencies and release checks can change which item starts next.

Each project has a GitHub tracking checklist. Check existing implementation before building; tests, release evidence and applicable live acceptance are required before marking an item delivered. Entries with implementation evidence remain awaiting acceptance.
