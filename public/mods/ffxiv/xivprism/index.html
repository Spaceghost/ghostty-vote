XivPrism

Your HUD, wherever you look.

A companion HUD project for glasses, extra monitors, phones and tablets. A standalone Prism app and combined presentation in native Moonlight share the same layouts.

Current status

design preview; live plugin and native companion apps are not released. The interactive preview uses invented data. Live game integration, native companion apps and hardware support have not yet been verified.

A second HUD, on your side of the connection

Keep FFXIV on its game screen and place selected information in your glasses or another display. Fedora supplies game state; display detection belongs to your remote client. Alienware and Win Max 2 can also supply local game state when playing natively.

An app when you just want Prism

The planned standalone Prism Display app receives HUD information without opening Moonlight. Phone, tablet, desktop and glasses outputs can have different layouts. A browser preview below demonstrates the layout choices with invented data.

Native Moonlight, with Prism around the game

Combined mode is planned for native Moonlight applications. Ordinary overlays will be evaluated where supported; restricted platforms may need a Prism-enabled native Moonlight build. Beam and neckband presentation must be checked on the exact model before support is claimed.

Peripheral first, pinned afterward

Start with sparse, readable panels and a clear centre. Whole-surface pinning can use capabilities already supplied by the glasses. Independent spatial panels and physical-monitor alignment are later work, depending on tracking and calibration.

Remember the glasses you actually use

Associate a display with a profile once. During an active companion session, plugging in those glasses should activate that profile. Unplugging, stale data and viewer failure must close the output and release any optional native HUD relocation.

The HUD family, connected

Journal, Character, Wayfinder and Piano are planned panel sources. XivMcp will report viewer readiness, actual presentation and recovery state. The display feed will be independent of high-frequency MCP tool calls.

Compatibility is a test record

Windows clients, Android phone and wearable clients, and iPadOS are targets. Ordinary display output, simultaneous Moonlight use, whole-surface pinning and spatial panels are separate capabilities. No glasses model, native companion app or live game connection has been verified yet.

Preview and source

The interactive browser preview and its native Imba source are available now. No installable Dalamud plugin or native companion app is released yet.

The browser preview needs no game, account or glasses. Live integrations are planned.
