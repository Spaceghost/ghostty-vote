One illustrated family

Passive player, target, focus and party panels, with casts and status effects. The family uses stitched leather, brass, compass ornament and game fonts. Explore the Umbra UI family.

Open from Umbra

Use /xivvitals open to show the passive panels, or /xivvitals preview for sample data.

Development installation

The modules use the explicit development Dalamud repository. Umbra toolbar DLLs are separate assets in the same development release. Add the adapter DLL in Umbra Settings → Plugins, restart Umbra, then choose the widget in the toolbar editor.

Keep the original within reach

Native chat, hotbars and job gauges remain available. Preview data is labelled and cannot send chat or trigger actions. Chat history stays in memory for the current session.

Install and build

Add https://spacegho.st/mods/ffxiv/plugins.json in Dalamud’s Experimental settings and enable plugin testing builds. These are experimental builds. The installation page explains the repository and the build-it-yourself path.

Dalamud API 15. The game module provides data and input; the optional Umbra plugin adds its toolbar button.

Build instructions and verification records are in the project README.
