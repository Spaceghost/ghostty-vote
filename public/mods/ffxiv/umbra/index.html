Umbra · illustrated UI family

An adventurer’s interface

A journal, a record, a battle deck, and your correspondence.

Stitched leather, warm vellum, brass and aether. The same materials and game fonts carry through every page of this UI replacement family.

Umbra toolbar plugins and game modules

Journal, Character, Combat and Correspondence have Umbra toolbar adapters. Their Dalamud modules read the game, draw the illustrated UI and handle explicit input. The Umbra plugins provide configurable buttons, readiness and appearance shortcuts. They are two connected parts of the same mods.

Install the family

Use the normal repository for HUD and Journal. Character, Vitals, Combat and Chat use the explicit development repository.

Download the Umbra adapter DLLs from development releases. In Umbra Settings → Plugins, add each DLL path and restart Umbra, then add the corresponding widget in its toolbar editor. A left click toggles the module; a right click opens appearance. Ctrl+Shift+right-click retains Umbra’s widget settings.

These remain development builds. Module loading and offline tests are checked; the revised visuals and native action/chat behavior still need live acceptance. Native windows and controls remain within reach.
