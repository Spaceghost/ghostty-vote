XivCamp

Unfold your little corner of Eorzea.

A saved-layout project for your map rug, journal, music, conversations and world windows. Make a campfire, work corner or adventure arrangement and return to it.

Current status

design preview; live plugin and native companion apps are not released. The interactive preview uses invented data. Live game integration, native companion apps and hardware support have not yet been verified.

A place for the tools you already have

Campfire brings Rug, Piano, Journal and Lantern together. Work corner adds Dispatch, notes and a terminal. Adventure favours Wayfinder and compact Prism information. Each arrangement remembers what belongs there.

Begin on the screen

The first implementation target is a saved screen layout: panel selection, position, size and display assignment. The interactive preview switches invented arrangements and exports a draft. It does not move real plugin windows.

Then unfold it into the world

Ghostty world windows and Rug placement are later integrations. A scene should retain an ordinary screen recovery path whenever a world host is missing or unavailable. A picture of a campsite is concept artwork, not evidence that furniture is being spawned.

One arrangement, several displays

With Prism, a Camp arrangement can send navigation to glasses, a journal to a tablet and work conversations to another monitor. Display mappings remain owned by the receiving client.

Controller-friendly and reversible

Opening Camp should have explicit focus ownership. Closing it, switching scenes or losing an optional provider should restore the previous arrangement. Missing panels should be reported individually rather than breaking the whole scene.

What still needs proving

Live window ownership, restoring positions, world placement, music actions and controller navigation need acceptance with the actual modules. There is no live plugin integration or installable Dalamud release in this publication.

Preview and source

The interactive browser preview and its native Imba source are available now. No installable Dalamud plugin or native companion app is released yet.

The browser preview needs no game, account or glasses. Live integrations are planned.

Build instructions and verification records are in the project README.
