Your modded Eorzea, on the screen you choose.

Current status

release candidate · Incus/Sunshine/NVIDIA path tested; other routes experimental. Verification below describes earlier recorded checks; the new publication and IPC work have offline validation.

Play on the screen you choose

XivStream sets up your modded FFXIV host for Moonlight clients or browser streaming. Its wizard detects the machine, then asks for the choices it cannot infer.

Review the plan

xivstream detect describes the host, xivstream plan -v shows planned commands and file changes, and xivstream doctor checks the setup. Review the plan before applying it.

A host tool

This runs outside the game and is downloaded from its GitHub releases. It is not installed through Dalamud’s plugin repository. The same source project contains Sunshine, Wolf and Selkies setup options.

What has been tested

The recorded end-to-end hardware path is Fedora with Incus, Sunshine and NVIDIA, including streaming input, audio and mods. Other hosts and streaming backends remain experimental. The published release candidate predates the local Wolf and CPU-policy work; those changes need reconciliation before a new release.

Install and build

Download the release candidate from GitHub releases. Run xivstream detect and review xivstream plan -v before applying changes.

Build instructions and verification records are in the project README.
