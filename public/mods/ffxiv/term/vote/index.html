What should the terminal do in Eorzea next?

Ghostty for FFXIV is a plugin that puts a real Ghostty terminal inside Final Fantasy XIV, made by Johnneylee Jack Rollins (github.com/Spaceghost). These are ideas for what it could do next. Each was checked against how the plugin actually works: how feasible it is, how much effort it takes, and whether it stays client-side and within the game's terms of service.

Mark each idea Want, Maybe or Skip, leave a note, or suggest something the list missed. The tallies help decide what gets built next. None of this is a promise that an idea will ship.

Privacy. No accounts. Your votes, notes and suggestions are saved on the server as you make them, next to a one-way hash of a random, anonymous ID held in a cookie that only this page can use, and the page loads them back from there whenever you open it. A copy is kept in this browser's local storage so the page can show them straight away. This site does not store IP addresses or personal details. Notes and suggestions are visible only to you and the maintainer. The tallies can be up to a minute old. Fonts load from Google Fonts.

Clearing this site's cookies starts a new, empty ballot in this browser; the server keeps the old one, but the page can no longer find it. Made by Johnneylee Jack Rollins, github.com/Spaceghost.
